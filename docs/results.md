# リザルトの保存

スキルドッジとスキルショットの結果（リザルト）を保存するしくみと、保存するファイルの形式をまとめます。保存した結果は、リザルト画面とメニューの「記録を見る」で直近 10 回を表示し、統計（手順 6）でも使います。

## 保存するルール

| ルール | 内容 |
|---|---|
| 保存するプレイ | 制限時間まで遊んだプレイだけ。ポーズから「はい」でメニューに戻ったプレイと、「リスタート」したプレイは保存しない。練習場（制限時間なし）は保存しない |
| 保存先 | `results/<モード>/<日付>.json`。モードは `dodge`（スキルドッジ）と `shot`（スキルショット）。例: `results/shot/2026-10-25.json` |
| 1 日の上限 | モードごとに 1 日 20 件まで。21 件目からは、その日の最も古い結果を消して上書きする |
| 残す期間 | 180 日分（約 6 か月）。暦の日数で数え、今日を含めて 180 日より前の日のファイルは、起動した時と保存した時に消す |
| 日付 | 制限時間になった時のパソコンの時刻（ローカル時刻）で決める |
| 読めないファイル | 名前の後ろに `.broken` を付けて残し（例: `2026-10-25.json.broken`）、次の保存で上書きしない。メニューの「記録を見る」に赤字で出る |

`results` フォルダは、遊んだ人ごとの記録なので git では管理しません（`.gitignore` に書いてあります）。

入力スクリプト（`--script`）で動かした時は、`--results-dir <フォルダ>` を指定した時だけ、そのフォルダに保存します（動作確認のプレイで、普段の記録を汚さないため）。

## 直近 10 回の表示（順位表）

- モードごとに、最も新しい 10 回のプレイを、成績の順（スキルドッジはドッジ率、スキルショットはヒット率の高い順）に並べます。同じ割合なら総数が多い順、さらに同じなら新しい順です。
- 1〜3 位は金・銀・銅の色で表示します。
- リザルト画面では、今回のプレイを強調し、「直近 10 回の中で何位か」を表示します。
- メニューの「記録を見る」では、モードごとのタブに順位表を出し、最も新しいプレイを強調します。

## ファイルの形式

1 ファイルが 1 日分で、その日の結果を古い順に並べた JSON の配列です。結果 1 件の項目は次のとおりです。

| 項目 | 意味 |
|---|---|
| `version` | 形式の版（今は `1`） |
| `playedAt` | 保存した日時（`"2026-10-25 22:40:12"`。ローカル時刻） |
| `mode` | `"dodge"` / `"shot"` |
| `character` | 自キャラ（`id` = 設定ファイルの id、`name` = 表示名） |
| `stage` | ステージ（`id`・`name`） |
| `timeLimit` | 制限時間（秒） |
| `playedSeconds` | 遊んだ時間（秒） |
| `cooldown` | クールダウンの設定（`mode` = `"standard"` / `"none"`、`scale` = 標準の倍率） |
| `seed` | 乱数の種（同じ展開を再現する時に使う） |
| `hits` | 自キャラのスキルのヒット率（`casts` = 発動した数、`hits` = 当たった数）。制限時間の終了時に飛んでいる途中だった発動は含めない |
| `hitsBySlot` | キーごとのヒット率（`"Q"` など。発動したキーだけ） |
| `enemies` | スキルドッジだけ。敵の数（`count`）と賢さ（`level`・`levelName`） |
| `dodge` | スキルドッジだけ。敵の発動の数（`total`）、避けた数（`dodged`）、当たった数（`hit`） |
| `hitsTaken` / `deaths` | スキルドッジだけ。被弾した回数・ダウンした回数 |
| `target` | スキルショットだけ。的の賢さ（`level`・`levelName`）、大きさ（`radius`・`sizeName`）、移動速度（`moveSpeed`） |

例（スキルショット）:

```json
[
  {
    "character": { "id": "like_ezreal", "name": "like ezreal" },
    "cooldown": { "mode": "standard", "scale": 0.25 },
    "hits": { "casts": 12, "hits": 5 },
    "hitsBySlot": { "Q": { "casts": 9, "hits": 4 }, "W": { "casts": 3, "hits": 1 } },
    "mode": "shot",
    "playedAt": "2026-10-25 22:40:12",
    "playedSeconds": 60.0,
    "seed": 1447571065,
    "stage": { "id": "open", "name": "障害物なし" },
    "target": { "level": 3, "levelName": "ふつう", "moveSpeed": 340.0, "radius": 65.0, "sizeName": "標準" },
    "timeLimit": 60.0,
    "version": 1
  }
]
```

## ソースコード

| ソースコード | 何をしているか |
|---|---|
| `src/game/ResultStore.cpp` / `ResultStore.h` | 保存と読み込み。1 日の上限・残す期間・直近の結果・順位の並べ方・JSON との変換 |
| `src/ui/RecordsPanel.cpp` / `RecordsPanel.h` | 直近 10 回の順位表と、メニューから開く記録の画面 |
| `src/ui/ResultScreen.cpp` | リザルト画面に、今回の順位と順位表を出す |
| `src/app/App.cpp` | 起動時に読み込み、制限時間になったら保存する |
| `tests/test_results.cpp` | 1 日の上限・残す期間・直近の結果・保存と読み込み・読めないファイル・順位のテスト（一時フォルダを使う） |
