# MOBA Trainer

MOBA（LoL・エターナルリターンなど）のスキルショットとスキルドッジを練習するためのソフトです。
要件は [claude_directive.txt](claude_directive.txt)、キャラの仕様は [character_traits.txt](character_traits.txt) にあります。

## 現在の状態（手順 4）

- モード
  - 練習場: ダミーを相手にスキルを試す（ダミーの大きさ・数・位置・動き方は、メニューか画面右下でプリセットから選ぶ）
  - スキルドッジ: 敵（1〜5 体）が撃ってくるスキルを避ける。制限時間（1〜5 分）の後にリザルト画面
  - スキルショット: 動き回り、スキルを避けようとする的（1 体）にスキルを当てる。制限時間（1〜5 分）の後にリザルト画面
- ステージ（どのモードでも選べる）
  - 障害物なし
  - 路地裏: 建物の間を路地が通る。壁でふさがれた行き止まりもある
  - 森: 木とブッシュ（草むら）が多い。ブッシュの中のキャラは外から見えない
- キャラ: like emma、like ezreal、like brand（スキルドッジでは敵としても登場）
- これから: リザルトの保存、統計

## ステージのルール

- 壁・建物・木・箱は通れません。壁の向こうを右クリックすると、回り込む道を自動で探して進みます（敵も同じ）。
- 弾や範囲は、壁や木を通り抜けます（地形が妨げるのは移動だけ）。
- ブッシュの中のキャラは、ブッシュの外から見えません。同じブッシュの中にいれば見えます。
  - ブッシュの中で対象指定のスキル（エマの E など）を使うと、3 秒間だけ外から見えるようになります（`data/settings.jsonc` の `bushRevealTime`）。
  - 自キャラがブッシュに隠れている間、敵は最後に見えた位置を狙います。
  - 自キャラがブッシュの中にいる時は、頭上の下に「ブッシュ: 隠れている」または「見えている」と出ます。

## ビルド

```text
build.bat            # Release ビルド → build\release\moba_trainer.exe
build.bat debug      # Debug ビルド   → build\debug\moba_trainer.exe
```

必要なもの: Visual Studio Build Tools（C++ によるデスクトップ開発）。
ライブラリ（raylib / Dear ImGui / ImPlot / nlohmann/json / doctest）は初回ビルド時に自動で取得します。

C++ のコードの書式は [.clang-format](.clang-format) で決めています。VSCode では `Shift + Alt + F` で整形できます。
コマンドで整形する場合は、clang-format（`pip install clang-format` で入る）を使います。

## 操作

| 操作 | 内容 |
| --- | --- |
| 右クリック | 移動（押しっぱなしでカーソルを追いかける） |
| Q / W / E / R / D / F | スキル（キーを押した瞬間にカーソル方向へ発動） |
| Y | カメラの切り替え（自キャラに固定 / 固定しない）。メニューでも選べる |
| Space | 押している間、自キャラを画面の中央に映す |
| 画面の端にカーソル | カメラを固定しない時に、その方向へカメラが動く |
| F1 | デバッグパネルの表示切り替え |
| F5 | 設定ファイルの再読み込み |
| Esc | スキルドッジ・スキルショット: ポーズ（メニューに戻る・やり直す・続ける を選ぶ）／ 練習場・リザルト画面: メニューに戻る |
| Alt + Enter | 全画面の切り替え |

プレイ中は、カーソルがウィンドウの外に出ません（画面の端でカメラを動かせるように）。
メニュー・リザルト画面に移った時と、Alt + Tab などで別のウィンドウに切り替えた時は解除されます。
ウィンドウを動かしたり閉じたりする時は、Esc でポーズするか、メニューに戻ってください（ポーズ中も解除されます）。

## スキルドッジ

- メニューで「敵の数」（1〜5 体）と「敵の賢さ」（1〜5）、制限時間を選びます
- 自キャラの HP は 5 段階。5 回被弾するとダウン数が 1 増えて全回復します
- 自キャラはすべてのスキルを使えます。攻撃スキルが敵に当たってもダメージはありません（状態異常はかかります）
- ドッジ率 = 敵の 1 回の発動のうち、自キャラに 1 つも当たらなかった割合
  （発動で出た弾・範囲がすべて消えた時点で確定。制限時間の終了時に飛んでいる途中のものは数えない）
- 敵として登場するのは、設定ファイルで `"usedByEnemy": true` のスキルを持つキャラです

## スキルショット

- メニューで「的の賢さ」（1〜5）・「的の大きさ」（小さい・標準・大きい）・「的の移動速度」（340 / 375 / 385 / 400）と制限時間を選びます
- 的は 1 体で、スキルを撃ちません。自キャラから 11m（1100）以内で、往復・接近して切り返す・ランダムな移動・停止のパターンを組み合わせて動きます
- 賢さには 2 つの軸があります
  - 避け方: 賢いほど、自キャラの弾・範囲に早く気づいてよく避け、詠唱（構え）を見て先に避けます。どの賢さでも、反応は人の限界と言われる 0.15 秒より速くなりません
  - 動き方: 賢いほど、パターンを多く混ぜ、往復の回数・幅をばらつかせ、ときどきリズムを崩して（大きく動く・少しだけ動いてすぐ切り返す）、動きを読まれにくくします
- 自キャラはすべてのスキルを使えます。ヒット率に数えるのは、方向指定・地点指定の攻撃スキル（`countsForHitRate`）だけです
- ヒット率 = 発動のうち、的に当たった割合（1 回の発動で弾が複数出ても、どれか 1 つが当たれば命中 1 回）
  （制限時間の終了時に飛んでいる途中のものは数えない）
- 的の大きさ・移動速度の選択肢、自キャラとの距離、賢さごとの動きは `data/ai.jsonc` の `skillShot` で変えられます

## ポーズ（スキルドッジ・スキルショット）

- プレイ中に Esc を押すとポーズし（制限時間も止まる）、「ゲームを中断して、メニューに戻りますか？」と出ます
  - はい: メニューに戻る ／ いいえ（または Esc）: プレイに戻る（そのままの状態で続く）／ リスタート: 同じ設定で最初からやり直す

## 調整できる設定ファイル

ゲームを起動したままファイルを保存すると、自動で再読み込みされます。

| ファイル | 内容 |
| --- | --- |
| `data/characters/*.jsonc` | キャラとスキルの数値（項目の説明は like_ezreal.jsonc の先頭） |
| `data/ai.jsonc` | スキルドッジの敵 AI（賢さ 1〜5 ごとの反応速度・狙い方・撃つ間隔など）と、スキルショットの的（大きさ・移動速度の選択肢・賢さごとの避け方と動き方のパターン） |
| `data/stages/*.jsonc` | ステージ（広さ・建物・壁・木・箱・ブッシュの配置）。書き方は open.jsonc の先頭 |
| `data/sandbox.jsonc` | 練習場のダミーのプリセット（当たり判定の大きさ・移動速度・数・位置・動き方）。選んだプリセットはこのファイルに保存される |
| `data/settings.jsonc` | 文字・ボタンの大きさ（`uiScale`）・視点の広さ・クールダウン倍率の初期値・ログの詳しさなど |

## ログ

`logs/` フォルダに出力されます（1 ファイル 20MB まで、作成日時で数えて 10 日分を保持）。
スキルドッジ・スキルショットを始めた時の「乱数の種」もログに残ります。不具合を見つけたら、その時のログファイルを添えて伝えてください。

## 自動での確認

```text
build\release\moba_tests.exe       # ゲームロジックの自動テスト
build\release\moba_trainer.exe --character like_ezreal --mode dodge --enemies 3 --ai 3 --time 12 --seed 42 --script tests\scripts\dodge_tour.txt
build\release\moba_trainer.exe --character like_ezreal --mode shot --ai 3 --time 8 --seed 42 --script tests\scripts\shot_tour.txt
```

`--script` は入力スクリプト（書式は `src/input/ScriptInput.cpp` の先頭）どおりに操作し、指定した時刻の画面を PNG で保存します。
コマンドライン引数の一覧は `src/app/CommandLine.h` にあります。
