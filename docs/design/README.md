# MOBA Trainer 詳細設計書

MOBA Trainer のソースコード（`src/` と `tests/`）の詳細設計書です。初めてこのソースコードを読む人が、動作と仕組みを理解し、変更できるようになることを目的にしています。

## この設計書が対象にしているコード

| 項目 | 内容 |
|---|---|
| 書いた時点のコード | この設計書を追加したコミット（2026-10-30）。`0498fab`（手順 6: 統計の画面（ダッシュボード）を追加する）に、設計書を書く中で見つけた点の修正（報告ファイルの A1〜A5・B1・B2・B6・B7・C4・D1〜D4）を加えたもの |
| 報告ファイル | 設計書を書く中で見つけた、コードと資料の食い違い・不具合の可能性と、その対応状況: [design-doc-findings.md](../../design-doc-findings.md)。設計書の「背景」で「報告ファイルの B1」のように書いているのは、このファイルの項目 |
| 対象 | `src/` のすべてのファイル、`tests/` のすべてのファイル、ビルドの設定（`CMakeLists.txt`・`build.bat`） |
| 対象外 | 設定ファイル（`data/`）の項目の説明は [data-files.md](../data-files.md)、リザルトの保存形式は [results.md](../results.md)、Windows の拡大率への対応は [dpi-scaling.md](../dpi-scaling.md) にあるので、この設計書では重ねて書かずにリンクします |

> **コードと食い違った時は、コードとヘッダーの説明コメント（`///`）が正しい** とします。
> この設計書は上のコードの時点で書いたもので、後の変更（手順 7 のキャラ追加など）では更新されていない場合があります。

## 書き方の決まり

### 各クラス・関数の説明の形

モジュールごとのファイル（10〜20 番台）は、次の順に書いています。

1. モジュールの概要（何をするモジュールか・他のモジュールとの関係）
2. 型の一覧（と、継承関係）
3. 型ごとの説明: 役割 → 背景 → メンバ変数 → メンバ関数 → 注意事項
4. 自由関数（クラスに属さない関数）の説明

ファイルの中だけで使う関数（`.cpp` の無名名前空間の中の関数）も、処理を理解するのに必要なので載せています。

### 「背景」の書き方

そのクラス・関数が作られた理由や経緯を「背景」に書いています。根拠があるかどうかで書き分けます。

| 表記 | 意味 |
|---|---|
| **背景**（根拠: …） | コミットのメッセージ、[claude_directive.txt](../../claude_directive.txt)（指示書）、[character_traits.txt](../../character_traits.txt)（キャラの仕様）、コードのコメントなど、書かれた根拠がある |
| **背景**（推測） | 根拠になる記述が見つからず、コードの形から推測した |

コミットは先頭 7 文字（例: `8c72709`）で示します。`git show 8c72709` で中身を見られます。

### 表記

- 「手順 N」は、指示書にある開発の段階です（手順 1 練習場 → 2 スキルドッジ → 3 ステージ → 4 スキルショット → 5 リザルトの保存 → 6 統計 → 7 キャラの追加）。
- 距離の単位は「ゲーム内単位」（LoL と同じ単位。100 がおよそエターナルリターンの 1m）、時間の単位は秒です。
- ファイルへのリンクは、リポジトリの中の相対パスです。
