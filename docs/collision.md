# キャラ同士の押し合いと当たり判定

キャラ同士がぶつかった時の動き（押し合い）と、それに関わる当たり判定（キャラの大きさ・障害物との当たり・弾が後ろに当たらない決まり）をまとめます。

- この文書は、**ソースコードの動きを正として**書いています（2026-11-25 時点）。コードを変えた時は、この文書も合わせて直してください。
- 仕様の一覧（確認済み・Claude判断の印付き）は [claude_directive.txt](../claude_directive.txt) の「押し合い」、設定ファイルの項目は [data-files.md](data-files.md)、クラスと関数の説明は [design/14-game-world.md](design/14-game-world.md) の 9 章（`UnitCollision`）と 4.5（`OverlapPass`）にあります。
- 押し合いの仕組みを使うスキルの動き（ワープの着地で押し合いを無くす許可を付けるスキルなど）は、スキルの設計書 [design/15-game-skills.md](design/15-game-skills.md) の各スキルの節にあります。

## 1. 言葉

| 言葉 | 意味 |
|---|---|
| 刻み | ゲームを進める単位。1/120 秒 |
| 押し合い | キャラ同士が重ならないように、重なった時に外へずらすこと |
| 押し合いの半径 | キャラ同士がぶつかる大きさ（`Unit::collisionRadius`。キャラのファイルでは `collisionRadius`）。2 体の中心の距離が、2 体の押し合いの半径の合計より短いと「重なっている」。ちょうど合計と同じ距離なら重なっていない |
| 当たり判定の半径 | スキルが当たる大きさ（`Unit::radius`。キャラのファイルでは `hitboxRadius`）。障害物との当たりと経路探索にも使う。画面に描くキャラの円の大きさでもある |
| 動いた側 | その刻みに位置が変わったキャラ（歩いた・ワープした）。前の刻みの終わりの位置（`Unit::prevPos`）と比べて決める（5.1） |
| 押し合いを無くす許可 | キャラに付ける「この相手とは押し合わない」という許可（`OverlapPass`。6 章）。スキルや状態が付ける |

## 2. 決まりの一覧

| 場面 | 動き |
|---|---|
| 誰と誰が押し合うか | すべてのキャラ（自キャラ・スキルドッジの敵・スキルショットの的・練習場のダミー）が、互いに押し合う。陣営には関係ない。押し合いを無くす許可を持つ組だけは押し合わない |
| ぶつかった時 | **動いた側だけ**が相手の外へずれる。止まっている側は押されない。両方動いていたら、半分ずつずれる |
| 歩きながらぶつかった時 | 1 刻みごとに押し出すので、歩いている側は相手の円に沿って滑る |
| 真正面に近い向きでぶつかった時 | 進む向きの右側へ回り込む。右側が障害物でふさがっていて左側が空いていれば、左側へ（5.3） |
| 押し出した先が障害物の時 | 障害物から押し出し直す（障害物が優先）。両側とも障害物だと、挟まって動けなくなることがある |
| 止まったまま重なっている時 | どちらかが動くまで、重なったまま（5.5） |
| ワープした時 | ワープした側が「動いた側」になり、同じ刻みのうちに相手の外へ押し出される（7 章） |
| 経路探索 | キャラを避けない（障害物だけを見て道を作り、ぶつかった所で上の決まりで回り込む） |
| 練習場の往復するダミー | 押し合いで挟まって 1 秒ほとんど動けなければ、往復を折り返す（9 章） |

## 3. 大きさ

### 3.1 値

| キャラ | 当たり判定の半径 | 押し合いの半径 |
|---|---|---|
| like emma | 45 | 30 |
| like ezreal | 55 | 30 |
| like brand | 55 | 30 |
| 練習場のダミー | プリセットの `radius`（小さい的 35 / 標準・動く的・距離の練習 55 / 大きい的 90） | 20 |
| スキルショットの的 | メニューで選ぶ（小さい 35 / 標準 55 / 大きい 90） | 20 |

- 2 体が近づける距離は、2 体の押し合いの半径の合計です。キャラ同士は 60、キャラとダミー（的）は 50、ダミー同士は 40 まで近づきます。
- 単位は、100 が ER の約 1m です。

### 3.2 どの処理がどちらの半径を使うか

| 処理 | 使う半径 | コード |
|---|---|---|
| キャラ同士の押し合い | 押し合いの半径（2 体の合計） | [UnitCollision.cpp](../src/game/UnitCollision.cpp) の `separate` |
| 押し合いを無くす許可の「離れきったか」 | 押し合いの半径（2 体の合計） | `collision::overlapping` |
| スキルの当たり（まっすぐ飛ぶ弾・追尾する弾・範囲） | 当たり判定の半径 | [World.cpp](../src/game/World.cpp) の `updateProjectiles` など |
| 障害物（壁・建物・木・箱・ステージの端）との当たり | 当たり判定の半径 | `World::updateUnit`、[Terrain.cpp](../src/game/Terrain.cpp) |
| 経路探索 | 当たり判定の半径 | `World::moveAlongPath` → `Terrain::findPath` |
| ワープ先の調整（壁の中を指定した時） | 当たり判定の半径 | [SkillHelpers.cpp](../src/game/skills/SkillHelpers.cpp) の `teleport` |
| 押し合いで押し出した後の、障害物からの押し出し直し | 当たり判定の半径 | `collision::resolve` |
| 回り込む側がふさがっているかの判定 | 立てるかどうかは当たり判定の半径、横へずらす距離は押し合いの半径の合計 | `headOnSlide` |

キャラ同士は押し合いの半径の合計（キャラ同士なら 60）まで近づけますが、壁には当たり判定の半径（45〜55）までしか近づけません。LoL では地形との当たりにも移動の半径を使いますが、遊んで違和感が無く、問題も起きないため、この形を仕様としています（2026-11-25、ユーザーの判断）。

## 4. 1 刻みの流れ

`Match::update` は、入力（自キャラ）→ 練習場のダミーの動き → 敵 AI → 的の AI → `World::update` の順に呼びます。入力で使ったスキル（ワープを含む）は、`World::update` より前に実行されます。

`World::update` の中:

1. すべてのキャラを、加えた順に進める（`updateUnit`）: クールダウン → 詠唱（スキルの発動。ワープもここ）→ 歩く（このとき歩いた量で `Unit::walking` を決める）→ 障害物から押し出す → 状態異常の残り時間
2. **押し合い**（`collision::resolve`）
3. 弾・範囲・設置物・演出を進める

`collision::resolve` の中:

1. すべてのキャラの押し合いを無くす許可を更新する（残り時間を減らす・離れた相手を外す。6.3）
2. それぞれのキャラが「押し出される側」かを決める: 前の刻みの終わりの位置（`prevPos`）から 0.001 より多く動いた、または「すぐ押し出す」の印（`pushOutNow`）が付いている
3. 重なっている組を押し出す（5.2〜5.4）。1 回り目だけ、真正面に近い時の横へのずらし（5.3）も行う。押し出した組が 1 つでもあれば、押し出される側を障害物から押し出し直して、もう 1 回り。最大 4 回り
4. すべてのキャラの `prevPos` を今の位置にし、`pushOutNow` を消す

全員が動いた後にまとめて直すので、キャラを動かす順番には左右されません。ただし、重なった組を直す順番はキャラを加えた順で、直した位置はすぐ次の組の計算に使うので、3 体以上が重なった時などは、その順番で結果がわずかに変わります。

## 5. 押し出し方

### 5.1 「動いた側」

- 前の刻みの終わりの位置（`prevPos`）と、押し合いの直前の位置を比べます。歩いた分と、ワープした分が入ります。その刻みに障害物から押し出された分も入ります。
- 押し合いで押された分は入りません（押し合いの最後に `prevPos` を今の位置にするため）。
- キャラを置いた刻み（`World::addUnit`）は、`prevPos` を置いた位置にするので、動いていない扱いです。
- 「すぐ押し出す」の印（`pushOutNow`）が付いたキャラは、動いていなくても押し出される側になります（6.4）。

### 5.2 押し出す量と向き

- 重なっている量（押し合いの半径の合計 − 中心の距離）だけ、相手の中心から離れる向きへずらします。
- 片方だけが押し出される側なら、その側が全部ずれます。両方なら半分ずつ、互いに反対向きへずれます。どちらも押し出される側でなければ、何もしません。
- 2 体がぴったり同じ位置（距離 0.0001 以下）の時は、向きが決まらないので、押し出される側が向いている方向（`facing`）の逆へずらします。両方が押し出される側なら、片方（先に加えた方）が自分の向きの逆へ、もう片方がその反対へずれます。

### 5.3 真正面からぶつかった時

押し出すだけでも、斜めにぶつかった時は相手の円に沿って滑ります。しかし真正面に近いと、押し出す向きが進む向きのほぼ真逆になり、横へほとんど進まないので、相手の前で止まってしまいます。そのため、次の時だけ横へずらす量を足します（`headOnSlide`。1 回り目だけ。押し出す割合（全部 / 半分）を掛ける）。

1. **真正面に近いか**: この刻みに動いた向きと、「相手の中心への向き」の差が 20° より小さい時。
2. **回り込む側**: 差が 2° より小さければ（ほぼ真正面）、進む向きの右側。それ以外は、相手から見て自分がずれている側。
   - 画面の座標は y が下なので、右へ進む時の「右側」は画面の下、上へ進む時の「右側」は画面の右です（`geo::perpendicular`）。
3. **ふさがっているか**: 回り込む側へ「2 体の押し合いの半径の合計」だけずらした位置に、当たり判定の半径で立てなければ（障害物・ステージの外）、そして反対側には立てるなら、反対側へ回り込みます。両側とも立てなければ、元の側のまま（挟まって動けなくなる）。
4. **ずらす量**: 押し出すだけでも、横へ「動いた量 × sin(差の角度)」だけ進みます。回り込む側へ、合わせて「動いた量 × sin 20°」（動いた量の約 0.34 倍）進むように、足りない分を足します。ずれている側と反対へ回り込む時は、押し出しで逆へ進む分も打ち消します。

例: 移動速度 375 のキャラは 1 刻みに約 3.1 進むので、真正面にぶつかった直後は、1 刻みに約 1.1 ずつ横へずれていきます。回り込むにつれて差の角度が 20° を超え、そこからは押し出すだけで滑ります。

**背景**（2026-11-24）: 最初は「ほぼ真正面なら右側」だけでした。路地裏で、建物の縁に沿って回り道をする練習場の往復のダミーが、同じ縁に押し付けられた静止のダミーに真正面からぶつかり（当たり判定 40 で押し出した位置と、回り道の位置が同じ x にそろった）、右側の建物へ回り込もうとして止まっていたため（ユーザーが実機で見つけた）、ふさがっている側を避けるようにしました。

### 5.4 障害物との関係

- 1 回り押し出すたびに、押し出される側のキャラを、当たり判定の半径で障害物とステージの外から押し出し直します（`World::placeable`）。障害物の方が優先です。
- 4 回り直しても重なりが残ることがあります（3 体以上が重なった時・障害物と相手に挟まれた時）。残った重なりは、次の刻みにまた直します。
- 両側とも障害物でふさがっていると、相手の前で止まったままになります（ユーザーの判断で許容。LoL でも、ミニオンとタワーの間などで起きる）。練習場の往復のダミーだけは折り返します（9 章）。

### 5.5 止まったまま重なっている時

どちらも動いていなければ押し出さないので、次の時は重なったままです。どちらかが動き出すと、動いた側が押し出されます。

- 置いた位置が重なっている（練習場のプリセットで、重なる位置にダミーを書いた時など）
- 押し合いを無くす許可が時間切れで終わった時に、まだ重なっている
- 押し合いを無くす許可で重なったまま、どちらも動かない（特例のワープの後。6.6）

## 6. 押し合いを無くす許可（`OverlapPass`）

### 6.1 考え方

重なることは基本的に禁止ですが、特定のスキルの使用時や状況では禁止が解かれる、という考え方です（2026-11-24、ユーザーの考え）。どのキャラにも、どのスキル・状態からでも付けられます（Dota 2 の Phased、LoL の Ghosted と同じ考え方）。

**2 体のどちらかが、相手を対象に含む許可を持っていれば、その 2 体は押し合いません**（`collision::passes`）。許可は押し合いにだけ効き、スキルの当たりなどには関係ありません。

### 6.2 中身

| 項目 | 意味 |
|---|---|
| `reason` | 付けた理由（ログ用。スキルの名前など） |
| `allUnits` | `true` なら、すべてのキャラが対象（すり抜け） |
| `targets` | 対象のキャラ（`allUnits` が `false` の時） |
| `remaining` | 残り時間（秒）。無ければ時間では終わらない |
| `endsWhenSeparated` | 対象と重ならなくなった相手は、対象から外す。誰も残らなければ終わる（`allUnits` なら、誰とも重ならなくなったら終わる） |
| `endsOnCastWhileMoving` | 重なったまま歩いている側が、新しくスキルの詠唱を始めたら終わる（6.4） |

### 6.3 毎刻みの更新

押し合いの最初（4 章の 1）に、すべてのキャラの許可を更新します。

- 残り時間があれば減らし、0 以下になったら終わり
- `endsWhenSeparated` なら、押し合いの半径で重なっていない相手・いなくなった相手を外す。誰も残らなければ終わり

終わった許可はその場で消え、その刻みの押し出しからは押し合いに戻ります（ただし、どちらも動いていなければ押し出されない。5.5）。許可が付いた・終わったことは、ログ（`collision`、DEBUG）に出ます。

### 6.4 重なったまま歩きながら詠唱を始めた時

`SkillCasting` は、新しくスキルを使い始めた時に `collision::onCastStarted` を呼びます。呼ぶのは次の時です。

- 詠唱を始めた時（`beginCast`）。詠唱時間 0 のスキル（ワープなど）・詠唱中に押して予約したスキル・射程外の対象へ近づいてから使うスキルも、ここを通る
- 詠唱中にすぐ使えるスキル（スキルの設定の `usableDuringCast` に書いたもの）を、詠唱を続けたまま使った時

`onCastStarted` は、そのキャラが**歩いていた**時だけ働きます。歩いていたかは `Unit::walking` で、直前の刻みの `updateUnit` で、道に沿って歩いて動いたかで決まります（ワープや押し合いで動いた分は入らない）。

歩いていた時は、

1. 自分が持つ `endsOnCastWhileMoving` の許可を、すべて終える
2. ほかのキャラが持つ、自分を対象に含む `endsOnCastWhileMoving` の許可から、自分を外す（`allUnits` の許可は外さない）。対象が誰も残らない許可は終える
3. 1・2 で何か終えたら、自分に「すぐ押し出す」の印を付ける。同じ刻みの押し合いで、動いていなくても（詠唱で足が止まっていても）、相手の中心から離れる向きへ押し出される（「飛ぶ」）

次の時は働きません。

- 止まったまま使った時（ワープの直後に、その場でスキルを使った時も）
- 許可が付く前に詠唱を始めていたスキルが、許可が付いた後に発動した時（溜めの間に特例のワープをして許可が付き、その後に溜めが終わって発動したスキル。発動は「使い始め」ではない）

### 6.5 特例のワープの着地（`collision::allowLandingOverlap`）

ワープしたスキルの処理が、ワープした直後に呼びます。その時に押し合いの半径で重なっている相手全員を対象に、`endsWhenSeparated`（離れきったら終わる）と `endsOnCastWhileMoving`（歩きながら詠唱を始めたら終わる）の許可を、ワープした側に付けます。誰とも重なっていなければ付けません。

どのスキルがこれを使っているかは、[design/15-game-skills.md](design/15-game-skills.md) の各スキルの節にあります。

将来の「すり抜け」の状態（[character_traits.txt](../character_traits.txt) にある「ユニットをすり抜ける」スキルなど）は、`allUnits` と `remaining` の許可で表せます。

### 6.6 特例のワープで重なった後の動き

| 着地の後 | 動き |
|---|---|
| どちらも動かない | 重なったまま |
| 相手が歩いて離れる | 押し合わずに離れる。ワープした側は押されない。離れきったら許可が外れる |
| ワープした側が歩き出す | 押し合わずに離れる。離れきったら許可が外れる |
| ワープした側が、歩きながら新しくスキルの詠唱を始める | 許可が終わり、ワープした側だけが相手の外へ押し出される（相手の中心から離れる向き） |
| ワープした側が、その場でスキルを使う | 押し出されない |
| 相手が、歩きながら新しくスキルの詠唱を始める | 許可から相手が外れ、相手だけが押し出される |

## 7. ワープ

- ワープするスキル（`teleport` を使うもの。フラッシュなど）は、移動先を当たり判定の半径で障害物から押し出してから置きます。向きはワープした方向になります。
- ワープした側は「動いた側」になるので、移動先にキャラがいれば、同じ刻みの押し合いで外へ押し出されます。相手は動きません。
- 相手の中心ちょうどへワープした時は、ワープした方向の逆（来た側）へ押し出されます（5.2）。
- 特例のワープ（6.5）は、押し合いを無くす許可を付けるので、着地した所で重なったまま残ります（6.6）。

## 8. 弾は出た位置より後ろに当たらない

- **まっすぐ飛ぶ弾**は、自キャラの中心から発射されたものとして、**発射した向きの反対側（出た位置より後ろ）には当たりません**（2026-11-23、ユーザーの確認）。追尾しない弾（`Projectile::homingTarget` が無い弾）すべてです。
- 追尾する弾（`homingTarget` がある弾）は、今までどおり対象に届けば必ず当たります。
- 弾は出た位置（`Projectile::origin`）を持ちます。`World::spawnProjectile` が、出た時の位置を入れます。
- 判定（`geo::sweptCircleHitsCircleAhead`、[core/Geometry.h](../src/core/Geometry.h)）: 弾の通り道（弾の半径の帯）の後ろの端を、「出た位置を通り、発射した向きに垂直な線」で平らに切った形で調べます。
  - 相手の中心が線より前なら、普通の判定（`sweptCircleHitsCircle`）と同じです。
  - 相手の体がすべて線より後ろなら、当たりません。
  - 中心は線より後ろでも、体の一部が線より前に出ていれば、前に出ている部分で調べます（線の上に中心を移した、半径 √(当たり判定の半径² − 後ろの距離²) の円で調べる。線の上では前に出ている部分の幅とちょうど同じで、線より前では少しだけ広い、当たりやすい側の近似です）。
- 背景: 以前は、1 刻み目の判定に「出た位置の周りの円」が入るので、出た位置の後ろにいる相手にも当たっていました（作り方の都合で生まれた動き）。そのため、相手に重なった所から撃つと、相手がどの向きへ逃げても必ず当たっていました。ER では弾は自キャラの中心から発射され、反対側には当たらないため、それに合わせて直しました。

## 9. 練習場の往復ダミーの折り返し

- 練習場の往復のダミーが、動ける状態なのに **1 秒**（`kPatrolStuckTime`）のあいだ、前に数えた位置から **5**（`kPatrolProgress`）以上離れられなければ、往復を折り返します（[DummyController.cpp](../src/game/DummyController.cpp)）。押し合いで、障害物と別のキャラの間に挟まって進めない時のためです。
- スタン・拘束・打ち上げなどで動けない間は、止まっていても数えません。
- 「目的地までの直線距離が縮んだか」ではなく「位置が動いたか」で見ます。壁を回り込む道では、いったん目的地から遠ざかることがあるためです（最初の作りでは、路地裏の回り道を「進めていない」と取り違えて、往復を終えられなかった）。
- 折り返したことは、ログ（`sandbox`、INFO）に出ます。
- 静止のダミーには、この処理はありません（止まっているので押し合いで押されない）。

**背景**（2026-11-24、ユーザーの判断）: 押し合いでは「挟まって動けなくなるのは許容」と決めましたが、練習場の往復のダミーが止まったままだと練習にならないため、折り返すことにしました。

## 10. ER との違いと、今の作りの限界

| 項目 | このソフト | 備考 |
|---|---|---|
| 押し出し方 | 1 刻みごとに滑らかに押し出す | ER は押し出しが少し遅れて、一気にずれる（相手の円の内側に約 0.15 秒入り込んでから押し出される場面があった）。通信の補正などによる動きかもしれず、まねしても練習の役に立たないため、まねしない |
| 障害物との当たり | 当たり判定の半径を使う | LoL は移動の半径を使う。遊んで違和感が無いため、この形を仕様とした（3.2） |
| 経路探索 | キャラを避けない | 敵 AI・的・ダミーも、ぶつかった所で回り込むだけ |
| 3 体以上の重なり | 直す順番（キャラを加えた順）で結果がわずかに変わる。4 回り直しても重なりが残れば、次の刻みに直す | 4 章・5.4 |
| 両側が障害物の時 | 挟まって動けなくなる | 練習場の往復のダミーだけは折り返す（9 章） |
| ほかのキャラの `allUnits` の許可 | 重なったまま歩きながら詠唱を始めても、ほかのキャラが持つ `allUnits` の許可は終わらない | 今はそういう許可を付けるスキルが無い |
| ノックバック | まだ無い | 押し合いを無くす許可の「外から押し出される」終わり方は、作る時に足す |

## 11. 経緯と ER の動画の分析

### 11.1 経緯

1. 2026-11-23: ユーザーの指摘がきっかけ。このソフトのエマの R（兎）は、兎の手前（エマ側へ「(兎の半径 + エマの半径) × 0.6」）に出ていたが、ER では兎にほぼ重なる（`skill_videos/emma_ER_behavior.mp4`）。仕様書の確認漏れだった。エマの R と EQR の今の動きは、[design/15-game-skills.md](design/15-game-skills.md) の 5.2・5.4 にある。
2. 直そうとして、このソフトにはキャラ同士の押し合いが最初から無い（キャラが自由に重なる）ことが分かり、押し合いから作ることにした。
3. ER の動画で押し合いの動きを分析し（11.2）、仕様をユーザーと決めた（claude_directive.txt の「押し合い」）。
4. 2026-11-24: 押し合い・押し合いを無くす許可・弾が後ろに当たらない決まりを入れた（コミット `942052c`）。ユーザーの実機確認で、路地裏の往復のダミーの詰まりを見つけて直した（回り込む側がふさがっていれば反対側へ・往復のダミーの折り返し）。
5. 2026-11-25: 当たり判定の半径が ER より少し大きいとユーザーが判断し、1 割ほど小さくした（40 / 50 / 65 / 100 → 35 / 45 / 55 / 90）。障害物との当たりは当たり判定の半径のまま、を仕様にした（コミット `73feb11`）。

### 11.2 ER の動画の分析

HP バーの上の線の色（ダミーは青緑、自キャラ（エマ）は紫、魔物は赤）でバーの位置を 1 コマずつ追い、相手に対する自キャラの位置を数値にしました。

| 動画 | 分かったこと |
|---|---|
| `skill_videos/collision1.mp4`・`collision2.mp4` | 自キャラは、ダミー・熊・ハウンド・鳥のどれも動かさなかった（ぶつかっている間、相手の HP バーが 1px も動かない）→ 動いた側だけがずれる。熊を横切ると、自キャラだけが進む向きと直角に 35〜40px 一気にずらされた |
| `skill_videos/collision3.mp4`・`collision4.mp4`（測定用） | 縮尺: HUD の移動速度 3.87m/秒と、真横に歩いた速さ（約 590px/秒）から、横は約 152px/m。自キャラが押し出された位置から、**自キャラ（エマ）+ イノシシ ≈ 0.5〜0.65m**。ダミーとは、中心から約 0.2〜0.4m の所を通っても押し出しが起きなかったので、**自キャラ（エマ）+ ダミー < 約 0.3m** |

- この測定を参考に、押し合いの半径はユーザーが決めました（キャラ 30・ダミーと的 20。今のキャラは全員が成人の人間型なので同じ大きさ。ER のダミーは一番小さいキャラくらいの押し合いを持つ）。キャラ 30 + ダミー 20 = 50 は測定（0.3m 未満）より大きいですが、ダミーの測定は「押し出しが起きなかった」ことからの推定で確度は中くらいです。
- ER の当たり判定（スキルが当たる大きさ）は、まだ測っていません。今の値（3.1）はユーザーの感覚で決めたものです。
